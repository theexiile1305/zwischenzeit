# Support

- **Questions and ideas:** use [GitHub Discussions](https://github.com/theexiile1305/zwischenzeit/discussions).
- **Bugs and feature requests:** open an [issue](https://github.com/theexiile1305/zwischenzeit/issues/new/choose) using a template.
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not open a public issue.

This is a volunteer project and is not affiliated with the vendor of TTools. For problems with
your TTools account, data or the TTools web app, contact TTools support.

Please never post patient data, real names, credentials or screenshots of live data.
